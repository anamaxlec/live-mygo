## 性能实现

视频使用 `mpv_render_context_set_update_callback` 按需唤醒，窗口完全遮挡或最小化时停止提交视频帧。界面线程不等待正在渲染的 drawable，尺寸更新合并到最新请求。带描边字图在单个后台工作槽中生成后复用，避免多个字图任务并发写入共享字体 atlas；动画帧不再重复绘制八遍轮廓。画面弹幕使用 MyGo 的 `Painter.AnimationFrameRate` 独立绘制，默认 60 fps，支持省电 30 fps 和跟随屏幕；没有消息时停止请求帧。滚动不会要求 mpv 重绘视频，也不重复构建整个界面。消息批处理只在消息抵达时开始定时；控制条自动隐藏后不维持轮询。封面和表情解码最多并发 4 个，位图缓存最多 96 个；失败释放 loading 标记，冷却 30 秒后可重试。弹幕设置滑块在停止拖动后合并写盘，避免逐帧同步文件。直播源意外结束时会重新获取短期播放地址，连续失败最多尝试三次。

性能报告中的 `max_main_thread_resize_ms` 只覆盖视频视图尺寸应用，不等同于整个窗口帧耗时。CPU 时间和渲染次数可用于比较当前场景的工作量，不等同于电池功耗的瓦数实测。

## 界面约定

标题栏与四周底板显示系统磨砂材质，下面的视频和弹幕栏由同一个四角圆角的容器承载，四周保留 4 DIP 窗口底板，容器边线 0.5 DIP 并带轻阴影、圆角 14 DIP；全屏移除这些占位，窗口跟随比例时纳入尺寸计算。评论区白底自身收圆角并裁切，外层容器统一绘制阴影，避免原生合成时留下白色方角。顶栏放直播间标题、主播和直播间操作，为系统窗口控件保留 `Context.TitleBar()` 占位。右侧弹幕容器撑满可用高度，连接面板只在内容区内叠加，跟随状态和官网互动入口固定在容器底部。小窗口控制条允许两行，避免压缩按钮点击区域。系统外观影响应用背景、底板、分隔线、文本和图标，视频控制条始终保持对比。原生视频保持直接渲染，圆角外侧由带 alpha 遮罩的小型系统材质视图覆盖，没有改动 GL context 或增加视频离屏转绘。

## 本轮审阅修复

切房开始即取消旧弹幕会话，并隔离迟到回调；解析新房间失败时列表也保持清空。普通消息与醒目留言分别保留 500 / 100 条，醒目留言使用独立接收队列，队列高峰省略数在列表菜单显示。关注页只请求房间元信息，不生成取流签名，最多并发 3 个、单请求 8 秒，进入时按需刷新并优先显示开播房间。

斗鱼重新逐段对照了 [Pure Live 的适配器](https://github.com/liuchuancong/pure_live/blob/master/lib/shared/platforms/douyu/douyu_danmaku.dart)、[Pure Live WebSocket 管理](https://github.com/liuchuancong/pure_live/blob/master/lib/core/network/web_socket_util.dart)、[Simple Live 的适配器](https://github.com/xuanxuan123xuan/dart_simple_live/blob/stable/simple_live_core/lib/src/danmaku/douyu_danmaku.dart) 与 [Simple Live WebSocket 管理](https://github.com/xuanxuan123xuan/dart_simple_live/blob/stable/simple_live_core/lib/src/common/web_socket_util.dart)。采用 8501–8506 加密候选端点、单端点 3 秒握手超时、45 秒心跳，以及可取消的串行恢复。普通消息、嵌套 STT 醒目留言、订阅登录包和候选端点故障切换有测试。Dart WebSocket 可在同机连接；捕获匿名握手确认服务端协商 TLS 1.2、RSA AES-128-GCM，Go 默认未启用该套件。经用户明确授权，为斗鱼公开弹幕提供独立兼容开关，仍验证证书与主机名、拒绝重定向、不使用 Cookie Jar；B 站、账号与取流使用原客户端。Go 20 秒验证收到 13 条消息，原生窗口也已显示真实弹幕。此套件缺少前向保密，开关默认关闭。

首帧报告将解码就绪和可见画面提交分开记录；观察粒度为 1 秒，不将其解释为精确呈现时刻。

### 固定弹幕 CPU 绘制对照

Apple M5，24 条固定文字和轨道，60 fps 目标，两轮各 1 秒的 CPU 软件绘制基准：逐帧描边为 10.44 / 10.63 ms，字图复用为 4.825 / 4.822 ms；每帧分配从 1080 次降至 0 次。基准不包含首次字图生成，也不表示原生 GPU 帧耗时或电池功耗。真实直播前后采样分别为约 110 / 97 秒，消息量不同，因此不把两轮进程 CPU 百分比差异当作严格优化幅度。

## 首页与播放状态

首页将关注正在直播、最近观看与平台推荐分组，关注状态和封面异步加载。首页保持滚动位置，避免新插入的关注分组被锚点推到视口上方。个人卡片沿用列宽，单张卡片不撑满整行。推荐封面短暂淡入，加载失败可从菜单重试。

侧栏播放卡片显示连接中、直播中、暂停或中断，提供暂停、静音与重连；这些操作保持当前浏览页面。播放页侧栏使用 220 ms 过渡，反向操作从当前尺寸继续；启用窗口跟随比例时直接调整尺寸。控制条支持 K 唤出及 Tab 顺序导航，键盘焦点或菜单在控制区时保持可见，回到画面后恢复自动隐藏。

新配置的画面弹幕默认 24 号、500 字重、80% 不透明度、4 条轨道、顶部 35% 区域；“推荐样式”可只恢复画面样式，保留账号和列表偏好。同屏相同文字可合并，弹幕列表仍保留各条消息。列表默认气泡，可切换紧凑模式，醒目留言继续独立强调。
