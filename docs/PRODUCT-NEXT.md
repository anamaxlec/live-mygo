# 产品进展（2026-11-13）

当前测试版为 `0.4.2-beta.6`，提供 macOS Apple Silicon 和 Windows x64 安装包。

`beta.6` 加入多路直播监控室和沉浸式观看，同一窗口最多播放九路直播，单路与监控室都能收起顶栏并在鼠标移动时唤回控制条。Windows x64 安装包与便携包已随该版本补发；本轮 Windows 实机验证覆盖本地播放与渲染，监控室多路、沉浸交互和安装器安装/覆盖升级仍待补充验收。

`beta.4` 修复直播分区切换后仍显示默认列表的问题，macOS 安装包最低版本为 26.0。macOS 26.6.2 虚拟机已验证 mpv 软件播放和旧原生硬解设置的回退。

`beta.3` 接入系统媒体控件与房间封面，适配 macOS 27.3 菜单栏「播放中」实时活动。直播间可收拢为播放卡片并从卡片展开，也可选择「展开侧栏」；弹幕栏可拖得更窄。新版 Windows 媒体控件和往返动效待实机回归。

`beta.2` 修复原生音频时间线、切回前台画面和内核重启提示，统一设置页排版及深色圆角底色。首页保留推荐与滚动位置，在后台刷新并过滤未开播房间；返回列表时直接恢复侧栏布局，主窗口与设置窗口分别保存位置和大小。

1. **连接恢复。** 先刷新当前地址，再尝试平台返回的其他线路，最多自动恢复三次。失败后保留房间身份、重试、播放设置和诊断入口；只有弹幕失败时使用可展开的紧凑卡片。
2. **诊断。** 导出版本、内核、实际解码器、音视频状态、画面提交、重试次数和最近错误分类；报告不包含播放 URL、请求头、Cookie 或令牌。macOS 可打开系统崩溃记录目录。
3. **版本。** 在关于页检查正式版或测试版更新，打开下载页及已有历史版本。当前使用手动下载安装，未加入签名自动替换与自动回滚。
4. **搜索与关注。** 快捷搜索默认查全部来源，本机关注和历史优先，网络结果并行返回；链接自动识别，纯房间号沿用当前来源。关注支持别名、分组、置顶与单独订阅通知。
5. **陪伴。** 只听声音会关闭视频解码和画面弹幕，保留音频及列表；可恢复画面或重新取流回到实时。原有小窗、置顶和定时停止继续保留。
6. **迁移与恢复。** 在「设置 → 通用 → 数据」导入或导出关注、分组、偏好和屏蔽规则。导入合并已有关注，备份不含账号和观看历史。可以选择启动时恢复上次房间、画质和线路，自动恢复始终静音。
7. **开播提醒。** 只检查主动订阅的关注，首次观察不通知；观察到下播到开播的变化后，遵循免打扰、允许时段和最短通知间隔。无订阅时不定时轮询。
8. **系统媒体控制。** Now Playing 显示房间身份，接入播放、暂停、停止；不为直播提供虚构时长和进度拖动。音量键沿用系统音量。
9. **多窗口。** 最多三个直播窗口，额外窗口默认静音、沿用默认画质、小窗观看，隐藏小窗内不接收弹幕；取消一个窗口的静音会将其他窗口静音。退出先释放播放器和视频视图，再销毁窗口。
10. **画面与片段。** 观看页菜单保存 PNG 原始画面或约 30 秒 MKV 片段。两种内核复用当前音视频连接，复制压缩数据；暂停、换房、换线时结束片段。提供进行中状态及保存位置入口。

界面补充了应援票式关注反馈、频道快门和弹幕信封收纳；读取已有状态不播放庆祝动画，动作结束后停止请求帧，遵循系统减少动态效果。数据分组使用统一设置行，不再铺满大按钮和说明。

## 备份互通

- Live MyGo 自动识别本应用 JSON、Simple Live 配置包和旧版单独导出的设置或关注，以及纯粹直播的 TXT/JSON 备份。导出时选择目标格式。纯粹直播的「仅关注」文件用该应用的关注恢复入口打开。纯粹直播的恢复会替换对应数据，3.x 还可能重置备份中缺省的设置，在已有数据的设备上恢复前先保留一份原备份。
- 跨应用迁移覆盖哔哩哔哩、斗鱼、虎牙和抖音的关注，以及两边能对应的主题、音量、弹幕和关键词屏蔽。外部多个分组归入一个本地分组，已有本地别名和分组优先保留。跨应用导入 Simple Live 时可选择合并。
- 开启「局域网互传」后，同一局域网的另一台设备用浏览器打开链接，可下载所选格式或上传备份。上传须在 Live MyGo 确认，链接 5 分钟后或关闭设置时失效。

## 实际验证

- 完整 race 回归、macOS vet、Windows 交叉 vet 已运行；最终复验命令见 macOS 与 Windows 文档。
- macOS 原生窗口走通备份导入导出、诊断导出、更新查询、别名和分组、跨来源搜索、只听声音及恢复、独立窗口、关闭与整体退出。
- 原生硬解混合测试约 36 分钟，包含本地样本和斗鱼 5720533（邦Sa），记录约 4.3 万次实际画面提交，全程保留 AAC。6657 已下播后的等待日志不作为播放成功证据。
- 原生截图样本为 640×360，mpv 真实直播截图为 960×540；两种内核均生成包含 H.264/AAC 的短片段，并用 ffprobe 检查。原生片段约 31.6 秒，mpv 片段约 30.4 秒。
- mpv 录制改从缓存的关键帧开始。macOS 上用本地 FLV 和经 HTTP 分段发送的 FLV 样本确认首个视频包是关键帧，FFmpeg 完整解码音视频时无报错。
- 原生菜单清空弹幕曾暴露同一帧列表下标失效的 panic，已固定本帧消息切片，补上菜单触发回归并重新在原生窗口验证。

## 新增观看功能

- 从浏览器或聊天软件把官方直播间链接拖进窗口即可打开。双画面下，拖到副画面会切换副路。
- 播放中，在房间卡片或快捷搜索结果的菜单选择「在副画面播放」。可以交换主副画面或单独切换声音，弹幕列表跟随主画面。
- 直播间菜单可进入系统画中画。macOS 使用 AVKit。Windows 使用 Compact Overlay，需要 Windows 11 和 [Windows App Runtime 2.x](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/downloads)。
