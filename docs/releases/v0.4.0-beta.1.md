# Live MyGo v0.4.0-beta.1 测试版

个人练手项目的首个公开测试版，用于学习 MyGo 原生界面、播放器集成与弹幕绘制。

- 推荐、分区、主播搜索、房间号与链接直达，本机关注和观看历史。
- 内嵌播放器悬浮控制条，可切换清晰度与线路，支持全屏及窗口跟随画面比例。
- 默认右侧气泡弹幕，画面弹幕可调整字体、颜色、描边、速度和布局，支持本机屏蔽。
- 官方登录窗口与 Cookie 导入，本机加密保存账号信息。
- 系统深浅色、磨砂底板与圆角内容容器，观看时可用 `⌘L` / `⌘K` 快捷切换房间。

下载 DMG，将 `LiveMyGo.app` 拖入 `Applications`；也提供 ZIP 包。需要 **macOS 27.0+、Apple Silicon**。当前使用 ad hoc 签名，尚未经过 Apple 公证。

后续计划见 [README 的待做事项](https://github.com/anamaxlec/live-mygo#待做事项)。
