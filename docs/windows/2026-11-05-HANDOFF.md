# 2026-11-05 新功能交接

当前安装包为 `0.4.2-beta.4`。下面保留前两轮的回归项，本次 Windows x64 包仍待实机验证。

## 本轮范围

- 搜索：全部来源并行返回，本地关注、历史和别名优先。
- 关注：分组、置顶、别名、开播订阅，通知含免打扰、时间段及频率限制。
- 数据：合并导入和导出 JSON 备份，静音恢复上次会话。
- 播放：只听声音、回到实时、三次线路恢复、紧凑的弹幕失败卡片、诊断导出。
- 多窗口：最多三个，额外窗口默认静音和较低画质，取消静音时切换主音轨，关闭前等待播放器释放。
- 系统媒体控制、更新通道查询、截图与短片段保存。
- 动效：应援票、换台快门、弹幕信封收纳；新图标来自高松灯的 Q 版二次创作，源 SVG 与应用内 PNG 一起生成。

Windows 保持 `libmpv-render-sw`，不使用 macOS 的 VideoToolbox / Metal 原生内核，也不显示其切换选项。macOS 的 GPU 截图修正只在 `render_darwin.go`；Windows 截图需实测。

## 构建与优先回归

```powershell
go test ./...
go vet ./...
go run ./cmd/package-windows -test
```

先使用独立 `LIVE_MYGO_DATA_DIR` 与本地 H.264/AAC 样本，再测正在开播的房间。不要把配置或账号信息提交到仓库。

1. 在有数十条消息时，从弹幕列表菜单连续清空；核对动画中能接收新消息、点击无穿透错误。此处已修同一帧清空后的下标 panic，测试为 `TestClearingFromChatMenuKeepsCurrentFrameIndicesValid`。
2. 检查数据行两按钮的等宽、内边距，以及 100%–200% 缩放和窄窗口；关于、关注编辑、快捷搜索也检查焦点、键盘关闭和快速反向操作。
3. 拖动音量、静音与只听声音，确认关闭视频解码、恢复画面、暂停后回到实时；重启验证恢复房间、画质和线路且 `muted=true`。
4. 开三个窗口，第四个应被拒绝；切换有声窗口、单独关闭与整体退出，留意软件帧缓冲和播放器生命周期。先暂停其他声音再做音轨测试。
5. 保存 PNG 和 30 秒 MKV，用 ffprobe 检查音视频轨道，再实际播放首尾。mpv 录制在 macOS 样本中出现起始 GOP 参考帧警告，需继续完善。
6. 实际系统通知、媒体键、更新查询、备份合并和诊断脱敏。系统媒体控件检查当前有声窗口的标题和封面，并验证快速切房、旧封面延迟抵达及停止后清理。备份不含账号、历史和会话，诊断不含播放 URL 或请求头。

## beta.2 补充回归

- 六个设置分类改用共同分组、文字边线和右侧控件列。操作按钮统一为 88×30 DIP，选择框 170×30 DIP；账号使用双行状态。检查浅色、深色、760×540 窄窗口和 100%–200% 缩放，确认文字不被裁切、操作可点击。
- 首页切换到关注、历史或平台页再返回，应立即保留推荐卡片及滚动位置；超过一分钟后在后台刷新，各来源陆续返回。确认下播的房间应从推荐及缓存移除。
- 从直播间返回列表时，侧栏直接恢复完整宽度，浏览内容淡入；手动开关侧栏仍支持过渡及中途反向操作。检查返回时标题与网格不横向伸缩。
- 主窗口 `StateKey: "main"`、设置窗口 `StateKey: "settings"` 复用 MyGo 窗口存储，写入本机 `library.json` 的 `window_states`；普通、最大化、全屏及跨屏恢复需在 Windows 验证。小窗退出不应覆盖普通主窗口大小，导入导出备份不迁移窗口状态。
- macOS 的 AAC、VideoToolbox 和原生窗口圆角修复不改变 Windows 的 libmpv 音频路径。Windows amd64、`CGO_ENABLED=0` 的 `go vet ./...` 已通过。

## beta.3 补充回归

- 从房间收拢到播放卡片、再从卡片展开。连接中、未开播和只听声音时也要检查；展开中立即返回应反向收拢。另测「展开侧栏」选项及关闭卡片。
- 拖动弹幕分隔条到最窄再拉宽，确认按住不动时不会抖动；未开播时确认连接卡片仍能显示。
- 检查 Windows 系统媒体控件的封面、切房、暂停与停止。菜单栏「播放中」实时活动属于 macOS 27.3。
