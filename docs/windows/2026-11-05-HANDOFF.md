# 2026-11-05 新功能交接

本轮源码随 `0.4.2-beta.1` 同步。macOS 提供双内核安装包；Windows 共用界面和业务代码已做交叉检查，新功能未在 Windows 实机验收。Windows 下载包仍为 `0.4.1-beta.3`，不包含本轮新增功能，需按下面清单构建复验。

## 本轮范围

- 搜索：全部来源并行返回，本地关注、历史和别名优先。
- 关注：分组、置顶、别名、开播订阅，通知含免打扰、时间段及频率限制。
- 数据：合并导入和导出 JSON 备份，静音恢复上次会话。
- 播放：只听声音、回到实时、三次线路恢复、紧凑的弹幕失败卡片、诊断导出。
- 多窗口：最多三个，额外窗口默认静音和较低画质，取消静音时切换主音轨，关闭前等待播放器释放。
- 系统媒体控制、更新通道查询、截图与短片段保存。
- 动效：应援票、换台快门、弹幕信封收纳；新图标来自高松灯的 Q 版二次创作，源 SVG 与应用内 PNG 一起生成。

Windows 保持 `libmpv-render-sw`，不使用 macOS 的 VideoToolbox / Metal 原生内核，也不显示其切换选项。macOS 的 GPU 截图修正只在 `render_darwin.go`；Windows 截图需实测。

## 构建与优先回归

```powershell
go test ./...
go vet ./...
go run ./cmd/package-windows -test
```

先使用独立 `LIVE_MYGO_DATA_DIR` 与本地 H.264/AAC 样本，再测正在开播的房间。不要把配置或账号信息提交到仓库。

1. 在有数十条消息时，从弹幕列表菜单连续清空；核对动画中能接收新消息、点击无穿透错误。此处已修同一帧清空后的下标 panic，测试为 `TestClearingFromChatMenuKeepsCurrentFrameIndicesValid`。
2. 检查数据行两按钮的等宽、内边距，以及 100%–200% 缩放和窄窗口；关于、关注编辑、快捷搜索也检查焦点、键盘关闭和快速反向操作。
3. 拖动音量、静音与只听声音，确认关闭视频解码、恢复画面、暂停后回到实时；重启验证恢复房间、画质和线路且 `muted=true`。
4. 开三个窗口，第四个应被拒绝；切换有声窗口、单独关闭与整体退出，留意软件帧缓冲和播放器生命周期。先暂停其他声音再做音轨测试。
5. 保存 PNG 和 30 秒 MKV，用 ffprobe 检查音视频轨道，再实际播放首尾。mpv 录制在 macOS 样本中出现起始 GOP 参考帧警告，需继续完善。
6. 实际系统通知、媒体键、更新查询、备份合并和诊断脱敏。备份不含账号、历史和会话；诊断不含播放 URL 或请求头。
