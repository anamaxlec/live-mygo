# 0.4.2-beta.6 Windows 交接

`v0.4.2-beta.6` 已提供 macOS Apple Silicon 和 Windows x64 包。Windows 包随该 Release 补发，应用源码与 `v0.4.2-beta.6` 一致，监控室沉浸模式提交为 `40f3ee6`。本轮 Windows 实机验证覆盖本地播放与渲染，监控室多路、沉浸交互和安装器安装/覆盖升级仍待补充验收。

## 构建

在 Windows x64 的独立 checkout 中检出 `v0.4.2-beta.6`，使用 Go 1.27.3 和 NSIS 3.10。从仓库根目录运行：

```powershell
git switch --detach v0.4.2-beta.6
go run ./cmd/package-windows
$env:LIVE_MYGO_LIBMPV = (Resolve-Path .\build\windows-amd64\libmpv-2.dll).Path
go test ./...
go vet ./...
```

打包工具会下载并校验固定版本的 libmpv，已有归档可用 `-runtime` 指定。便携 ZIP 位于 `build/releases/`。生成 beta.6 安装器前，在 `cmd/package-windows/installer.nsi` 将 `APP_VERSION` 改为 `0.4.2-beta.6`，并将 `VIProductVersion` 改为 `0.4.2.6`。

```powershell
makensis /INPUTCHARSET UTF8 cmd\package-windows\installer.nsi
```

用隔离配置启动，准备至少两个确认在播的直播间。若需要先排查解码，用 `-file` 播放一段本地 H.264/AAC 视频确认出画后再进监控室。

```powershell
$env:LIVE_MYGO_DATA_DIR = Join-Path $env:TEMP ('live-mygo-windows-qa-' + [guid]::NewGuid())
.\build\windows-amd64\LiveMyGo.exe -report .\build\reports\windows-beta6.json
```

## Windows 实机验收

| 场景 | 验收条件 |
| --- | --- |
| 单路沉浸 | 底栏全屏左边的按钮和 `T` 都能切换。上下悬浮栏一起显隐，右侧弹幕列表可独立操作。缩放窗口或重新聚焦后检查右上角系统按钮的位置和点击区域。 |
| 监控室沉浸 | 默认有常驻工具栏。打开沉浸后画面区域扩到顶部，移动鼠标唤回工具栏和所指直播间的控制条，停约三秒后淡出。回到普通模式时系统按钮恢复，重复切换无跳位。监控室设置能跨重启恢复，单路沉浸设置独立。 |
| 全屏与返回 | `F11` 进出全屏。`Esc` 先关闭添加或音量面板，之后退出全屏或沉浸，普通窗口下再按 `Esc` 返回来源页。从监控室打开单路再返回，检查画面、动效和窗口按钮。 |
| 添加与布局 | 添加面板先显示关注，其次是最近观看。试用直播链接拖入、固定排列和自由拖动缩放，确认切换沉浸时保留格子顺序和相对位置。分别在 100%、150%、200% 缩放和跨屏移动后检查命中区域。 |
| 多路播放 | 先验证两路都能同时出声，每路音量、静音和弹幕独立，单路重连不打断其余画面。再用流畅档试 4 路及 9 路，记录 CPU、内存、丢帧及界面响应。当前上限是 9 路，尚无本版 Windows 9 路实测结果。 |

定位界面和播放问题可从 [监控室视图](../../internal/app/ui_monitor.go)、[自由布局](../../internal/app/ui_monitor_layout.go)、[沉浸与窗口按钮](../../internal/app/ui_immersive.go)、[Windows 视频容器](../../internal/player/surface_windows.go) 和 [交互测试](../../internal/app/ui_watch_modes_test.go) 入手。监控室沉浸状态保存在 `library.json` 的 `monitor.immersive`，单路播放使用 `preferences.immersive`。Windows 的窗口按钮由 MyGo 的 `MyGoCaption` 子窗口绘制，macOS 的原生按钮测试不能覆盖它。

## 补发

用便携包和安装器分别验证干净安装及从 beta.5 覆盖升级，检查关注、设置、直播播放和安装器版本。若 Windows 所用应用源码与 `v0.4.2-beta.6` 一致，实机验收通过后可为该 Release 补上 Windows 安装器、便携 ZIP 和对应 SHA-256，再更新 README 的 Windows 下载链接。若实机验收需要改动应用源码，用包含修复的新版本打包并发布。

旧版的检查更新会列出较新的 Beta 标签。Windows 下载以 Release 资产和 README 的平台版本为准。
